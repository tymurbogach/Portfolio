# Portfolio — Timur

## Stack

- **Astro 6** (static site, output `dist/`)
- **Tailwind v4** vía `@tailwindcss/vite` (config en CSS con `@theme`, `@utility`, sin `tailwind.config.js`)
- **TypeScript** (estricto, `astro/tsconfigs/strict`)
- **simple-icons** para logos técnicos
- **Build**: `npm run build` → `dist/`
- **Deploy**: Docker (Node 22+) + Nginx

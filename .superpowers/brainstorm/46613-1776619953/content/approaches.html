3 enfoques para la dirección "Técnico / Hacker"

Cada uno tiene distinto nivel de riesgo y cambio

A

Full Rewrite — Terminal OS aesthetic

Cambio radical: Reemplazar Poiret One con monospace completo. Boot sequence en home, comandos de terminal, CRT scanlines opcionales. Eliminar 7 temas → 2 (light terminal / dark terminal). Riesgo alto, impacto máximo.


⚠ Riesgo: puede alejar a recruiters tradicionales

B

Tech Layer — Capa hacker sobre base actual ✦ Recomendado

Evolución estratégica: Mantener Poiret One + 7 temas (identidad). Añadir una segunda fuente monospace (JetBrains Mono) para datos, stats, skills, badges. Stats del home como "system readout". Skills como manifest file. Homelab como "infraestructura live". Home: terminal typewriter intro.


✓ Equilibrio: distintivo pero profesionalmente legible

C

Polish + Micro — Misma dirección, más refinado

Mínima intervención: Mejorar spacing, jerarquía tipográfica y microinteracciones. Añadir indicadores de nivel en skills. Cards de proyectos más grandes. Nada de cambios de identidad visual.


↓ Menor impacto, menor riesgo
